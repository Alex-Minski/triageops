# Runbook: Equipment requests (monitors, keyboards, headsets)

**Category:** hardware · **Owner:** desktop_support · **Typical priority:** P4

## Resolution
1. Check the standard equipment catalogue. Standard items need no approval.
2. Non-standard items need the manager's approval before ordering.
3. If the item is in stock, schedule desk delivery within 3 business days.
4. Out-of-stock items: order them and tell the user the expected date.
5. Record the asset tag against the user in the asset register.
