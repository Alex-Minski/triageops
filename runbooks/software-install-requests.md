# Runbook: Software installation requests

**Category:** software · **Owner:** desktop_support · **Typical priority:** P4

## Resolution
1. Check the software portal: most approved apps (Python, Power BI Desktop, Visio viewer) are self-service.
2. Licensed software (Visio, Adobe Pro) needs a licence assignment and the manager's approval.
3. Software that isn't in the catalogue needs a security review before it is installed.
4. Install the app with the deployment tool, not by hand, so it stays patched.
5. Confirm the app launches, then close the ticket.
