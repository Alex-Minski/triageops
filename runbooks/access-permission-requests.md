# Runbook: Access and permission requests

**Category:** access · **Owner:** identity · **Typical priority:** P4

## Resolution
1. Identify the resource (shared folder, SharePoint site, application, project) and the access level requested (read, edit, owner).
2. Look up the resource owner in the access catalogue.
3. Send an approval request to the resource owner. Never grant access on the requester's word alone.
4. Once approved, add the user to the resource's access group rather than granting direct permissions.
5. Tell the user access can take up to 30 minutes to apply and that signing out and back in speeds it up.
6. Record the approver and date on the ticket for the quarterly access review.

## Notes
- Requests for admin or finance-system access also need the requester's manager's approval.
