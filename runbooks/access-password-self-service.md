# Runbook: Password questions and self-service reset

**Category:** access · **Owner:** service_desk · **Typical priority:** P4

## Resolution
1. Point the user to the self-service password reset portal. It needs a registered phone or authenticator.
2. Passwords must be at least 14 characters. They expire only when a compromise is suspected, not on a fixed schedule.
3. If the user hasn't registered for self-service reset, walk them through registration after verifying identity.
4. Remind the user to update the saved password on their phone's mail app to avoid a lockout.

## Never
- Ask a user to send their password in a ticket or email. If they do, reset that password immediately.
