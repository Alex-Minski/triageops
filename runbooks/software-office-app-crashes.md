# Runbook: Office, Teams or Acrobat crashes

**Category:** software · **Owner:** desktop_support · **Typical priority:** P3

## Resolution
1. Ask the user to install pending updates from the software portal and restart.
2. Excel crashing on large files: start Excel in safe mode (hold Ctrl while launching). If that is stable, disable add-ins one by one.
3. Teams closing on launch: quit Teams, clear its cache folder, and start it again.
4. Acrobat freezing: turn off Protected Mode at startup and test again, then repair the install.
5. Still crashing: run an Office online repair from Apps and Features.
6. Collect the crash time from the event log before escalating to applications.
