# Runbook: Calendar invites missing, shared mailboxes, distribution lists

**Category:** email · **Owner:** applications · **Typical priority:** P3; P4 for new list or mailbox requests

## Resolution
1. Missing invites: check whether a delegate is accepting invites on the user's behalf, then check the inbox rules.
2. Shared mailbox disappeared: confirm the user still has Full Access permission. It reappears automatically within an hour of being re-added.
3. Joining a distribution list: the list owner must approve. Send them the request.
4. New shared mailbox: needs a named owner and a purpose. Create it with the provisioning script, never by hand.
